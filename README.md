KademeuLivro

Projeto da faculdade UNA Aímores sendo desenvolvido por Victor Lael e Brian do cusro de Engenharia de Software.

Projeto de uma aplicação desktop desevolvida em Python com utilização, incial, do Tkinter.

Funcionalidades:
- Login e Registro
- Busca de livros utilizando Google Books API
- Visualização de detalhes dos livros
- Interface gráfica em Tkinter
- Integração com API REST

Tecnologias: 
- Python
- Tkinter
- Requests
- SQLAlchemy
- Pillow
- Python-dotenv

Posteriormente -> Custom Tkinter

Como executar:

```bash
pip install -r requirements.txt
python main.py
